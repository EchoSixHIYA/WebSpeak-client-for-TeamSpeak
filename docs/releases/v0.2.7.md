# WebSpeak 0.2.7

## 简体中文

0.2.7 带来完整的 KAAK 语音皮肤体验，并继续改进 TeamSpeak 连接、频道树、屏幕共享和跨平台发布。

- KAAK 增加独立的宽屏与窄屏语音工作区、频道树、聊天入口、服务器横幅、成员操作和语音控制；新增生成邀请链接的入口。
- 服务器密码和加密频道密码可以保存在当前浏览器中，减少重复输入。频道树会正确显示受密码保护的频道；固定服务器模式会说明管理员限制，并允许用户中断卡住的连接后切换服务器。
- 修复频道树和成员列表在窄屏下的布局，以及不同皮肤中的屏幕共享播放器宽度、比例和状态显示；增加屏幕共享码率选择，并根据浏览器能力选择编码器，保留 AV1 回退。
- 完善通用皮肤动作接口，使 KAAK 可通过受权限控制的运行时能力创建邀请链接。
- 修复管理后台将随应用内置的 KAAK 皮肤设为实例默认皮肤时失败的问题。

发布构建包含 Windows x64、Linux x64 和 ARM64、Docker amd64 和 arm64，以及 Android arm64-v8a、armeabi-v7a 和 x86_64 APK。Android APK 使用 debug 签名。自动构建与启动检查不代表已完成所有 TeamSpeak 服务器、设备或 Android 真机互通测试。

## English

Version 0.2.7 completes the KAAK voice-skin experience and continues work on TeamSpeak connections, channel navigation, screen sharing, and cross-platform releases.

- KAAK now has dedicated desktop and narrow-screen voice workspaces, a channel tree, chat entry, server banner, member actions, and voice controls. It can generate invite links.
- Server and encrypted-channel passwords can be remembered in the current browser. Protected channels are identified correctly. Fixed-server mode explains administrator restrictions and lets users interrupt a stalled connection before switching servers.
- Fixed narrow-screen channel-tree and member-list layout, plus screen-share player sizing, aspect ratio, and status across skins. Added share bitrate selection and browser-capability-based codec selection with AV1 fallback.
- Extended the generic skin action API with a permission-gated runtime action for creating invite links.
- Fixed setting the bundled KAAK skin as the instance default from the admin console.

Release builds cover Windows x64, Linux x64 and ARM64, Docker amd64 and arm64, and Android arm64-v8a, armeabi-v7a, and x86_64 APKs. Android APKs are debug-signed. Automated builds and startup checks do not claim complete interoperability testing with every TeamSpeak server, device, or Android handset.

## Deutsch

Version 0.2.7 vervollständigt das KAAK-Sprachskin und verbessert weiterhin TeamSpeak-Verbindungen, Kanalnavigation, Bildschirmfreigabe und plattformübergreifende Builds.

- KAAK bietet nun eigene Sprachbereiche für Desktop und schmale Bildschirme, Kanalliste, Chat-Einstieg, Serverbanner, Mitgliederaktionen und Sprachsteuerung. Einladungslinks können erstellt werden.
- Server- und verschlüsselte Kanalpasswörter lassen sich im aktuellen Browser speichern. Geschützte Kanäle werden korrekt erkannt. Im festgelegten Servermodus werden Administratoreinschränkungen erklärt; eine hängende Verbindung kann vor dem Serverwechsel abgebrochen werden.
- Korrigiert wurden die Layouts von Kanalliste und Mitgliederbereich auf schmalen Displays sowie Größe, Seitenverhältnis und Status des Bildschirmfreigabe-Players in verschiedenen Skins. Hinzu kommen eine Bitratenwahl und die Codec-Auswahl nach Browserfähigkeiten mit AV1-Rückfall.
- Die allgemeine Skin-Aktions-API enthält nun eine berechtigungsgeschützte Laufzeitaktion zum Erstellen von Einladungslinks.
- Die Auswahl des mitgelieferten KAAK-Skins als Instanzstandard im Adminbereich wurde repariert.

Die Builds umfassen Windows x64, Linux x64 und ARM64, Docker amd64 und arm64 sowie Android-APKs für arm64-v8a, armeabi-v7a und x86_64. Die Android-APKs sind mit einem Debug-Schlüssel signiert. Automatische Builds und Startprüfungen ersetzen keinen vollständigen Kompatibilitätstest mit allen TeamSpeak-Servern, Geräten und Android-Telefonen.

## Русский

В версии 0.2.7 завершена основная работа над голосовым скином KAAK и улучшены подключения к TeamSpeak, навигация по каналам, демонстрация экрана и сборки для разных платформ.

- В KAAK появились отдельные голосовые интерфейсы для широких и узких экранов, дерево каналов, переход к чату, баннер сервера, действия с участниками и голосовые элементы управления. Можно создавать ссылки-приглашения.
- Пароли сервера и зашифрованных каналов можно сохранить в текущем браузере. Защищённые каналы отображаются правильно. В режиме фиксированного сервера объясняются ограничения администратора; зависшее подключение можно прервать перед переключением сервера.
- Исправлена компоновка дерева каналов и списка участников на узких экранах, а также размер, пропорции и состояние плеера демонстрации экрана в разных скинах. Добавлены выбор битрейта и выбор кодека по возможностям браузера с резервным вариантом AV1.
- В общий API действий скинов добавлено создание ссылок-приглашений с проверкой разрешений.
- Исправлена ошибка при выборе встроенного скина KAAK в качестве скина по умолчанию в панели администратора.

Сборки доступны для Windows x64, Linux x64 и ARM64, Docker amd64 и arm64, а также Android APK для arm64-v8a, armeabi-v7a и x86_64. Android APK подписаны отладочным ключом. Автоматическая сборка и проверка запуска не заменяют полные испытания с разными серверами TeamSpeak, устройствами и Android-телефонами.

## 日本語

0.2.7 では KAAK 音声スキンを拡充し、TeamSpeak 接続、チャンネル操作、画面共有、マルチプラットフォームのリリースを改善しました。

- KAAK にデスクトップと狭い画面向けの独立した音声ワークスペース、チャンネルツリー、チャット入口、サーバーバナー、メンバー操作、音声コントロールを追加しました。招待リンクを生成できます。
- サーバーと暗号化チャンネルのパスワードを現在のブラウザーに保存できます。保護チャンネルを正しく表示します。固定サーバーモードでは管理者の制限を説明し、接続が停止した場合に中断して別サーバーへ切り替えられます。
- 狭い画面でのチャンネルツリーとメンバー一覧の配置、および各スキンでの画面共有プレーヤーのサイズ、比率、状態表示を修正しました。共有ビットレート選択と、AV1 を予備に残すブラウザー機能別コーデック選択を追加しました。
- 共通スキンアクション API に、権限で保護された招待リンク生成アクションを追加しました。
- 管理画面で同梱の KAAK スキンをインスタンスの既定に設定できない問題を修正しました。

リリースビルドは Windows x64、Linux x64/ARM64、Docker amd64/arm64、Android arm64-v8a、armeabi-v7a、x86_64 APK に対応します。Android APK はデバッグ署名です。自動ビルドと起動確認は、すべての TeamSpeak サーバー、デバイス、Android 端末との完全な相互接続試験を意味しません。
