# KOOK 语音客户端界面参考

本文依据用户授权查看的 KOOK 网页语音工作区，记录 WebSpeak 可复刻的语音界面。范围限定在指定服务器的前两个语音频道；不保存服务器或房间名称、标识、成员身份、聊天内容、截图或连接凭据。

## 界面结构与呈现

- 最左侧是纵向服务器栏；服务器内容区在其右侧，包含服务器信息和按组排列的频道。
- KOOK 有独立文字频道列表。它属于文字频道导航，不是语音频道附带的聊天；当前 WebSpeak 只复刻语音频道旁的聊天，不复刻这组独立文字频道。
- 语音分组行显示图标、频道名称及人数/上限。加入语音频道后，成员以缩进项目出现在频道行下方。
- 进入语音频道后，中央区域显示成员舞台。成员卡片为宽比例矩形，头像居中，静音状态标记放在卡片右上角。聊天展开时，姓名在静止状态下隐藏，悬停卡片后以紧凑标签显示在左下角；聊天收起时，姓名标签保持可见。
- 当前语音频道的文字聊天显示在右侧面板。面板标题对应当前语音频道，消息区占据主体，输入框固定在底部；展开时右上角有收起入口。收起后右侧聊天面板完全隐藏，中央成员舞台横向扩展，舞台标题栏右侧出现重新打开聊天的按钮。
- 左下方语音控制坞显示当前连接状态和离开入口，也有屏幕分享控件。屏幕分享为付费功能，按用户要求不列入 KAAK 复刻范围。
- 顶部客户端下载提示、服务器广告、推广卡、发现与运营页面都不属于 WebSpeak 皮肤范围。

## 交互观察

- 语音频道第一次点击后会选中频道并提示再次点击；再次点击才进入。加入后成员出现在该频道下方，当前语音频道聊天和语音控制坞同时出现。
- 在本次首次进入的两个授权语音频道中，当前频道聊天默认展开。这个结果只证明已观察的频道；音乐类语音频道仍需单独确认。
- 聊天展开时，成员卡默认不显示姓名；鼠标移到卡片上后姓名标签出现。收起聊天后，成员卡姓名持续显示，即使鼠标停在聊天收起控件附近也没有隐藏。
- 当前语音频道聊天展开时，中心成员舞台仍保留频道名和实时人数标题；成员卡是横向大卡片，头像居中，静音标记位于右上角。
- 从一个已加入频道切换到另一个授权频道时，成员归属和当前聊天标题随目标频道变化；本次切换前聊天面板已展开，所以切换后仍展开。这不能证明一个全新频道首次进入时聊天面板的默认折叠状态，尤其不能据此判定音乐语音频道的默认状态。
- 本次查看期间麦克风保持关闭，没有发送消息，也没有操作管理员功能。
- 当前页面呈现了中心成员舞台和右侧语音频道聊天；早期记录里“中心聊天、右侧成员列表”的描述与实际语音房间页面不符，已由本次原页观察更正。

## 音频与连接状态控件

- 左下语音坞用绿色信号柱表示连接状态，断开入口单独放在右上；音频开关排列在坞底部，图标按钮尺寸紧凑。屏幕分享按用户要求暂不作为复刻目标，也未操作。
- KOOK 的语音设置可从个人菜单进入，页面把输入/输出设备选择、麦克风输入音量和语音输出音量放在同一张深色设置卡片内；设备选择是下拉控件，音量使用横向滑杆，输入设备下方提供本地麦克风测试。
- 设置页采用分区标题、较清楚的正文标签和绿色强调色。没有拖动滑杆或更换设备，因此仅记录控件外观，不推断声音反馈或切换动画；KAAK 对应使用宿主现有滑杆和设备选择控件，并为悬停/键盘焦点补充皮肤反馈。
- 本次本地 KAAK 对照打开了 WebSpeak 的音频配置弹窗，没有更换设备、移动音量、启动麦克风测试或开启麦克风。设备名称不写入文档。
- 连接状态图标点击后未显示单独性能卡片。KAAK 将 WebSpeak 已有的通用性能面板做成紧凑状态入口；它是 KAAK 自己的诊断卡片，不能据此声称 KOOK 具有相同面板。

## WebSpeak 实现映射

1. 服务器栏映射为 WebSpeak 的收藏/历史快速切换栏。
2. 左侧频道树只映射 TeamSpeak 语音频道及在线成员；KOOK 的独立文字频道组不在当前范围。
3. 中央区域映射为语音成员舞台，使用 WebSpeak 的成员卡片和公开状态。
4. 右侧映射为当前 TeamSpeak 语音频道附带的文字聊天，可在语音房间内展开或收起。
5. 左下控制坞继续调用 WebSpeak 宿主音频和断开控件；付费屏幕分享不属于 KAAK 的复刻范围。

皮肤负责布局和视觉；TeamSpeak 连接及控制仍由 WebSpeak 宿主执行并校验。只复刻授权观察到的语音客户端行为，不复刻 KOOK 的发现、陪玩、派对、商城、活动、推广或管理后台。
