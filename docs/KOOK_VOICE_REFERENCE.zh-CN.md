# KOOK 语音客户端界面参考

本文只记录用户授权查看的 KOOK 网页语音工作区，用于设计 WebSpeak 的可换肤语音界面。参考范围限定为指定测试服务器的前两个语音频道。文档不保存服务器名、频道名、服务器标识、成员身份、聊天内容、截图或连接凭据。

## 界面结构

- 最左侧是窄服务器栏，使用纵向图标切换服务器，底部是当前用户入口。
- 服务器内容区展示服务器名称和信息，并按频道组组织文字频道与语音频道。语音频道行显示频道图标、名称和人数/上限；已加入频道时，参与者以缩进成员项显示，可见头像、昵称和静音状态。
- 中央工作区保留当前文字频道的消息流和输入区。加入或切换语音频道后，中央聊天仍留在原文字频道，不会被语音房间页面替换。
- 右侧成员栏按在线、离线分组，成员头像、昵称和状态纵向排列。
- 加入语音后，服务器内容区底部出现独立控制卡，显示当前语音频道、连接质量指示、离开连接、屏幕分享入口、标记为“REC”的入口，以及语音灵敏度、麦克风和耳机控制。只记录控件外观，不推断“REC”入口的具体功能。
- 顶端下载提示、服务器栏上方的广告和服务器频道区内的推广卡占用明显版面，但属于 KOOK 运营内容，不纳入 WebSpeak 皮肤范围。

## 交互观察

- 已授权查看前两个语音频道；频道列表顺序可以确认，本文不保存其名称或服务器标识。
- 首次点击语音频道会先选中该项，并提示再次点击进入；第二次点击后加入，自己的成员项出现在频道下方，底部控制卡同步显示当前频道。
- 从第一个频道切换到第二个后，连接转移到新频道，原频道人数减少、新频道人数增加；点击底部离开控件后断开，成员项和控制卡消失，频道人数恢复。
- 麦克风在加入前、加入期间和离开后均保持关闭。未开启麦克风或屏幕分享；界面中未见摄像头控件；未操作管理员功能。
- 参考仅用于观察布局与交互，不采集或复用聊天内容、成员资料、服务器素材或运营页面数据。

## WebSpeak 实现映射

目标布局按 WebSpeak 已有宿主能力组合，不复制 KOOK 的发现、陪玩、派对、商城、活动通知、排行榜或管理后台：

1. 服务器栏映射到 WebSpeak 收藏/历史快速切换栏。
2. 频道树映射到 TeamSpeak 频道与在线语音成员数据；频道切换继续调用 WebSpeak 宿主动作。
3. 中央区域保留 TeamSpeak 当前频道聊天和输入控件。
4. 成员侧栏使用 WebSpeak 成员列表、静音状态与经授权的成员操作。
5. 底部语音卡映射到 WebSpeak 音频设备、静音、语音模式、屏幕共享和断开控件，始终由可信宿主实现。

皮肤只决定布局和视觉；TeamSpeak 连接与控制仍走 WebSpeak 的权限校验和宿主能力桥。不要把 KOOK 账号、语音服务协议、成员隐私数据或站点素材复制到 WebSpeak。
