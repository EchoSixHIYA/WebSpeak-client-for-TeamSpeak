# KOOK 语音客户端界面参考

本文只记录用户授权查看的 KOOK 网页语音客户端界面，用于设计 WebSpeak 的可换肤语音工作区。参考范围限定为“比奇堡恶人帮”服务器前两个语音频道；未记录成员身份、聊天内容、服务器标识或任何连接凭据。

## 界面结构

- 最左侧是窄服务器栏，使用纵向圆角图标快速切换服务器；底部留有当前用户入口。
- 服务器内容区展示服务器名称和信息，其下按文字频道组、语音频道组组织频道。语音频道行呈现频道图标、名称、人数/上限；已加入频道时，参与者作为缩进成员项显示在频道下方。
- 中央工作区保留当前文字频道的消息流和输入区。加入语音频道后，聊天仍留在中央区域，不会被语音房间页面替换。
- 右侧成员栏按在线、离线分组，成员头像、名称及状态纵向排列。
- 连接语音时，左下角出现独立语音控制卡：当前频道与连接质量、离开频道、屏幕共享、麦克风/耳机/音量与语音感应控制。自己的成员项也出现在频道树中，并显示静音状态。
- 页面顶端和服务器栏中的广告、活动推广等内容属于 KOOK 运营内容，不纳入 WebSpeak 复刻范围。

## 交互观察

查看了授权的前两个语音频道。选中频道后页面提示再次点击进入；加入后左侧频道树新增自己的成员项，左下角出现连接控制卡。切换频道会把当前语音连接切换到新频道。退出连接后频道计数恢复，客户端显示可关闭的语音质量反馈提示。

整个观察过程未发消息、未开启麦克风或摄像头，也未操作管理员功能。频道名和计数只用于确认入口，不作为产品演示数据。

## WebSpeak 实现映射

目标布局按以下宿主能力组合，不复制 KOOK 的广告卡、发现/陪玩/派对、商城、活动通知或管理后台：

1. 服务器栏映射到 WebSpeak 收藏/历史快速切换栏。
2. 服务器频道树映射到 TeamSpeak 频道与在线语音成员数据；频道切换继续调用 WebSpeak 宿主动作。
3. 中央区域保留 TeamSpeak 当前频道聊天和输入控件。
4. 成员侧栏使用 WebSpeak 成员列表、静音状态与经授权的成员操作。
5. 左下语音卡映射到 WebSpeak 音频设备、静音、语音模式、屏幕共享和断开控件，始终由可信宿主实现。

不应把 KOOK 账号、语音服务协议、成员隐私数据或站点素材复制到 WebSpeak。皮肤只决定布局和视觉；TeamSpeak 连接与控制仍走 WebSpeak 的权限校验和宿主能力桥。
