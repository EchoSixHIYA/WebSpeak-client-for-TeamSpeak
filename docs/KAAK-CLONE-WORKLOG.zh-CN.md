# KAAK 语音界面复刻工作记录

这份记录用于跨会话续接。开始新一轮工作前，先看这里的“当前检查点”和“下一步”，再检查对应代码或 KOOK 原始页面；完成一个有意义的修改节点后追加记录，不按零碎操作逐条记。

## 固定范围和做事方式

- 以 KOOK 已商业化的语音房间页面为参考。遇到不确定或看起来不合理的交互、样式、动画时，先核对 KOOK 原始页面，再决定是否改动。
- 当前只复刻语音客户端体验。KOOK 独立的文字频道列表暂缓；只做随当前语音频道展开、可收起的文字聊天。
- WebSpeak 引擎只接受可复用的通用能力改进，不为 KAAK 单独适配。修复限定在已确认的问题，不顺手扩展无关代码。
- 相关节点累积后统一验证，避免每个小改动都重跑完整验证。
- 记录中不放服务器地址、密码、密钥、成员名单、聊天内容或其他隐私数据。

## 已完成的修改节点

- 语音房间整体布局已按 KOOK 的语音客户端结构实现：左侧服务器栏与频道树、中心成员舞台、右侧当前语音频道聊天、左下语音控制坞。独立文字频道列表不在本轮范围。
- 频道树支持折叠语音分组；当前语音频道的文字聊天在房间内展开或收起，不需要离开语音房间。
- 中心成员呈现已从小头像列表调整为宽比例成员卡片，使用宿主可信成员卡展示可用头像，并对说话、静音和成员加入/离开提供状态样式与动画。
- 成员姓名标签遵循聊天面板状态：聊天展开时静止隐藏，悬停卡片时显示；聊天收起时固定显示在左下角。姓名以外的成员卡布局和状态副行保持当前设计。
- 语音坞复用 WebSpeak 宿主的音频和断开控件；皮肤提供外观，不接管底层语音实现。KAAK 暂不提供付费屏幕分享功能。
- 最近节点增加了通用频道占用数和容量数据投影，KAAK 在有限容量频道显示上限，在未限制容量时不显示上限。此数据能力位于共享 TeamSpeak 频道模型，不是 KAAK 专属引擎分支。
