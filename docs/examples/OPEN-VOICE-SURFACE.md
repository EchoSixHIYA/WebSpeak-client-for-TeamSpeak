# Open Voice Surface scaffold

This importable schema v2 surface package exercises complete public home and voice pages using only declarative nodes and WebSpeak-owned controls. It includes server switching, channel navigation, visible members, chat, audio, whisper, screen sharing, connection controls, and the built-in language and skin selectors. It contains no discovery, events, shop, companion, advertising, or administration pages.

This is an implementation scaffold for testing the open-skin format, not a visual claim about KOOK. The current KOOK browser bridge does not expose the logged-in page, so its room-specific visual details remain unverified. Once the reference page can be read, the scaffold can be styled from the two authorized rooms without adding unrelated service pages.
