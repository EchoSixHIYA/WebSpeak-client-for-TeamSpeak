# Harbor Voice Workspace

这是一个 KOOK 语音工作区风格的完整皮肤测试包，参考范围只限语音客户端：服务器快捷栏、频道列表、中央聊天、成员列表和底部语音控制。没有复用 KOOK 的图片、标志、广告或站点文案，也没有加入发现、陪玩、派对、商城、活动通知、排行榜或管理后台。

皮肤使用 `components.json` 的安全声明式 surface 和 WebSpeak 宿主控件。频道树会在当前频道下显示已连接成员；双击频道才请求 TeamSpeak 加入，避免单击选中与加入混为一谈。服务器与频道列表只读取已授权的公开标签和状态；切换服务器、静音和断开都由宿主执行并校验。皮肤不读取服务器地址、账号凭据或连接密钥，也不包含可执行 JavaScript/Wasm；这个样例用于验证 v3 兼容 surface，v4 Wasm 插件运行时另由运行时测试覆盖。

桌面布局保留四个区域：服务器快捷栏、频道树、聊天区和成员区；连接后语音控制坞固定在频道栏底部。窄屏下服务器栏保持可用，频道项转为横向滚动，成员与语音控制各自占一行，基础连接控制不被隐藏。

`manifest.json`、`components.json` 与 `skin.css` 是可编辑源码。根目录的 `../harbor-voice.wskin` 是源码打包后的本地导入包；可在测试实例的皮肤管理页导入验证，当前没有加入公共皮肤目录或发布到服务器。
