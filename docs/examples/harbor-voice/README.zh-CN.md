# Harbor Voice Workspace

这是一个 KOOK 语音工作区风格的完整皮肤测试包，参考范围只限语音客户端：服务器快捷栏、频道列表、中央聊天、成员列表和底部语音控制。没有复用 KOOK 的图片、标志、广告或站点文案，也没有加入发现、陪玩、派对、商城、活动通知、排行榜或管理后台。

皮肤使用 `components.json` 的完整声明式 surface 自己构建频道树、聊天消息与输入框、成员状态和悄悄话控制；底部音频区嵌入 WebSpeak 的可信音频控件，继续使用现有麦克风/扬声器开关和音频设置（包括麦克风灵敏度）。样例隐藏与语音布局无关的伴奏开关；断开和频道控制仍由 WebSpeak 校验并执行。频道缩进直接映射 TeamSpeak 公开树深度；频道单击只改变皮肤本地选中态，双击才请求 TeamSpeak 切换频道。语音成员列表显示公开的说话、静音和离开状态。消息、频道和成员数据由权限筛选后提供。屏幕共享启动保留一个可自行排版和换肤的可信宿主按钮，以保留浏览器要求的真实用户手势；视频流和设备 API 不交给皮肤代码。皮肤不读取服务器地址、账号凭据或连接密钥，也不包含可执行 JavaScript/Wasm；这个样例用于验证 v3 surface 的可定制界面和交互，v4 Wasm 插件运行时另由运行时测试覆盖。

桌面布局保留四个区域：服务器快捷栏、频道树、聊天区和成员区；服务器栏底部展示当前 TeamSpeak 昵称，连接后语音控制坞固定在频道栏底部。昵称项只呈现当前会话身份，不模拟 KOOK 账号或资料运营功能。窄屏下服务器栏保持可用，频道项转为横向滚动，成员与语音控制各自占一行，基础连接控制不被隐藏。

`manifest.json`、`components.json` 与 `skin.css` 是可编辑源码。根目录的 `../harbor-voice.wskin` 是源码打包后的本地导入包；源码修改后运行 `npm run skin:harbor:build` 重新打包，再在测试实例的皮肤管理页导入验证。当前没有加入公共皮肤目录或发布到服务器。
